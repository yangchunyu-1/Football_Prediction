# 🏆 欧冠抽签 · 比分预测

一个纯前端网页应用：基于 **2026/27 赛季欧洲冠军联赛** 的 36 支正赛球队，支持**随机抽签**或**手动选择**两支球队进行对阵，然后根据球队实力与球员水平**模拟一场完整比赛**，生成包含阵容展示、进球、红黄牌、换人、进球取消（VAR）、乌龙球、终场哨等要素的**完整赛况时间轴**。

> 界面采用简约美观的**绿茵球场主题**（草坪条纹背景、球场中线装饰、金色点缀），适配桌面与移动端。

---

## ✨ 功能特性

### 1. 抽签与选队
- 内置 2026/27 赛季欧冠 **36 支已确认正赛球队**（按第一档～第四档分组，含国旗、国家、综合实力分、阵型）。
- 🎲 **随机抽签**：带滚动动画，随机抽出两支球队对阵。
- 🔍 手动选队：弹出式选队面板，支持中文 / 英文 / 国家**实时搜索**，点击即选。
- ⇄ 一键交换主客队；不允许选择同一支球队。

### 2. 赛前预测
- 双方**综合实力对比**展示。
- 基于双方进球期望值（泊松模型）的**蒙特卡洛胜平负概率**（主胜 / 平局 / 客胜进度条）。

### 3. 首发阵容展示
- 📋 预测开始时自动展示双方**阵型**（如 4-3-3、4-2-3-1、3-5-2 等）和**首发11人名单**。
- 按门将、后卫、中场、前锋分组显示，清晰直观。

### 4. 比赛模拟（完整赛况时间轴）
每次模拟由随机种子驱动，生成一条完整的赛况时间轴，包含：
| 事件 | 说明 |
| --- | --- |
| 🟢 开场哨 | 比赛开始 |
| ⚽ 进球 | 进球者、进球时间、助攻者、**进球后的即时比分** |
| ⚽ 点球命中 | 主罚球员与时间 |
| 🥅 乌龙球 | 自摆乌龙的防守球员 |
| ❌ 进球取消 | VAR 回放取消进球（越位 / 手球 / 进攻犯规 / 出界） |
| 🟨 黄牌 | 吃牌球员与时间 |
| 🟥 红牌 | 两黄变一红或直接红牌，且会影响后续进球概率 |
| 🔁 换人 | 上下场球员与时间 |
| ⏱ 半场哨 | 半场比分 |
| 🏁 终场哨 | 90 + 补时，最终比分 |

- **技术统计**：控球率、射门 / 射正、角球、越位、犯规、黄牌、扑救（与时间轴事件保持一致）。
- 🎖 **全场最佳**：按进球 + 助攻贡献评选。
- ▶ **播放赛况**：按时间顺序逐条揭示时间轴事件，比分牌实时跳动，还原直播观感。
- 🔁 **重新模拟**：同一对阵换一个种子再跑一次，结果不同。

## 🚀 使用方式

无需安装任何依赖，二选一：

1. **直接打开**：用浏览器打开 `index.html` 即可。

   ```bash
   python -m http.server 8080
   # 浏览器访问 http://localhost:8080
   ```

## ⚙️ 模拟模型说明

- **期望进球 λ**：由双方综合实力比（含主场优势）决定，`λ = 1.42 × (实力比)^1.5`，并通过**泊松分布**抽样两队进球数。
- **红牌修正**：比赛中若出现红牌，被罚下一方的剩余时间进球期望下调、对方上调。
- **进球者选择**：按位置加权（前锋 60 > 中场 30 > 后卫 10）× 球员能力分²，能力分 = 球队实力 + 稳定的姓名哈希抖动（同一球员分数恒定）。
- **在场约束**：引擎先确定所有事件的时间，再按"事件发生时是否在场上"分配球员——替补**登场后才能进球**，被换下或红牌罚下后不再产生进球、助攻、吃牌等事件；黄牌、红牌、换人之间也互相校验，杜绝"进球后才被换上""罚下后又被换下"等时间线矛盾。
- **首发阵容**：每队前 11 人为假定首发，按其阵型（formation 字段）排列展示，替补球员（12-23 号）在比赛中可被换上场。
- **其余事件**（黄牌数、换人次数、补时长度、VAR 取消等）均由经验概率分布抽样，保证时间线真实感。
- 所有随机数由 **mulberry32 种子发生器**驱动，同一种子结果可复现。
